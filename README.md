# Peaky Blinders - Fan Website

A cinematic, responsive fan website dedicated to the acclaimed television series **Peaky Blinders**. Designed with a vintage Birmingham aesthetic, dark cinematic visuals, elegant typography, and a gold-accented interface.

Explore the Shelby family's legacy, discover the story behind the series, and meet some of its most iconic characters.

---

## Preview

A dark, cinematic interface inspired by the atmosphere of 1920s Birmingham, featuring:

- Vintage-inspired typography.
- Dark charcoal backgrounds with gold accents.
- Full-screen cinematic hero section.
- Responsive image gallery.
- Series overview and storyline.
- Character profiles with actor portraits.
- Interactive hover effects and smooth navigation.

## Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension (recommended).

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_REPOSITORY_URL>
```

**2. Navigate to the project directory**

```bash
cd Web-show-template
```

**3. Open the project**

```bash
code .
```

**4. Run the website**

Open `index.html` using the Live Server extension in VS Code.

Alternatively, open `index.html` directly in your browser.
